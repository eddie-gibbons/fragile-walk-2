# Fragile Walk

This project is a work in progress...

This project is a succesor to [fragile-walk](https://github.com/eddie-gibbons/fragile-walk). The original game was fine, but clearly a very beginner project; for instance there was no sound. The art could have been better. In general the code was somewhat janky. With this project I hope to use a 'cleaner' architecture: having scene management and better seperation of concerns.

Additionally this is being programmed in lua with love2d, which is actually designed for making games.

## Installation
1. Make sure to have [**LOVE2D**](https://love2d.org/) installed.
2. Clone the repository and change directory
```bash
git clone https://github.com/eddie-gibbons/fragile-walk-2
```
3. Execute
```bash
love .
```
